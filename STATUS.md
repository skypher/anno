After defense logic, each aggressive AI (Military / Balanced) iterates the players it's at WAR with; when its score exceeds the enemy's, it picks the enemy's first active warehouse and orders ~half of its idle units (`target_x == tile_x && target_y == tile_y && combat_target < 0`) to march on it via `target_x/target_y`. `tick_unit_orders` then steps them across the map and `tick_combat` engages anything that gets in range. Caps at one front per tick to avoid splitting forces across multiple enemies. New `ai_marches_units_at_enemy_warehouse_when_winning` test seeds 4 idle AI units, declares war, and asserts ≥2 are now targeting the enemy warehouse
66. **Carrier cargo indicators** — every active carrier now stamps a small colored chip with a single-letter abbreviation just above its sprite while it's `CarryingGoods` or `Returning` and `carried_amount > 0`. Each of the 30 goods has its own thematic color (Wood brown, Gold yellow, Food red, Tools silver, Iron gray, etc.) so a glance at the map reads the active supply chain without having to right-click each carrier. New `cargo_chip` and `good_from_u8` helpers in the game binary keep the per-Good color/letter table local to the renderer (matches anno-sim's private decoder)
67. **Auto-pause for info panels** — opening any of the modal overlays (graph, production, roster, market, warehouse, fleet, save, scenario picker, tax, diplomacy, trade-route mode) now pauses the sim automatically so the player can read at leisure; closing them resumes. Tracked via `prev_modal_open` + `auto_paused` so the auto-unpause only fires when we were the ones who paused — manual `Space` while reading disarms the flag and the player keeps control
68. **AI gold reinvestment threshold** — `AiController::tick` now halves all three cooldowns (build / military / trade) at the start of each tick whenever the AI's gold exceeds 15 000. Stops the AI from sitting on a treasury pile while the player out-builds it. Combined with `SellExcess` handling at the low-gold end, the AI's economic loop has both bookends: it sells when broke, builds/raids harder when flush. Two new sim tests in `ai::tests` (`rich_ai_halves_cooldowns_each_tick`, `poor_ai_does_not_halve_cooldowns`)
69. **Per-good warehouse stock sparklines** — `EconomyHistory` gains a per-Good ring buffer (31 × 120 samples) populated by the new `record_full(player, warehouses, owner)` method which sums every active warehouse's stock per `Good`. `tick_population` calls it for player 0. Production overview panel now widens to ~460px and renders a self-normalised 90×8 sparkline at the right of each row, matching the row's color (green for actively-produced goods). Each row is independently scaled so a Wood spike doesn't flatten the Jewelry trace. Save format bumped to v6 for the new field; old saves get a backfill via `Vec::resize` on the `stocks` field. Two new tests (`record_full_captures_warehouse_stocks`, `record_full_sums_across_warehouses`)
70. **AI naval escorts** — `MilitaryUnit` gains `escort_ship: i32` (-1 = none). When at war, `tick_diplomacy` assigns each AI trade ship an idle naval unit as escort, or spawns a fresh `SmallWarship` at the ship's coords for 500 gold. New `combat::tick_escort_targets` runs every entity step, refreshing each escort's `target_x/target_y` from the shadowed ship — `tick_unit_orders` then walks the warship after the ship; `tick_combat` engages anything in range. Escort link clears automatically if the ship goes inactive. Save format bumped to v7 for the new field. Three new sim tests covering spawn, target tracking, and inactive-ship cleanup
71. **Manual ship construction** — F4 buys a `TradeShip` at the player's first active warehouse for 1000 gold. Spawns at the warehouse's tile, joins `sim.trade_ships`, ready to be assigned via R/Enter. Banner reports success or the failure reason ("not enough gold", "no warehouse"). No new sim state — the existing trade-ship vector and economy handle it
72. **Colony founding** — F7 drops a fresh Kontor (warehouse) on the active island for 500 gold when the player doesn't already have one there. Uses `IslandMap::find_open_spot` to land the 2×2 footprint near island center, seeds 100-unit capacity for the staple goods (Wood, Iron, Tools, Food, Cloth, Bricks, Stone, Grain, Flour, Wool, Sugar, Tobacco), and creates a `CoverageMap` for the island if none exists yet (so `tick_market_coverage` starts running). Banner reports failure modes (already have a Kontor, not enough gold, no buildable spot)
73. **Buildings take combat damage** — `BuildingInstance` gains a `health: u16` (default 100). New `combat::tick_building_damage` runs each military tick: hostile non-naval units within 2 tiles of a building's footprint drain 5 hp/tick each (so 5 swordsmen flatten a 100-hp building in ~4 military ticks). When health reaches 0, the building is removed, walkability restored, and a `(island_id, x, y, w, h)` event is pushed onto `Simulation::tile_clears`. The game binary drains it each frame to clear `Island::tiles` (so the static renderer stops painting the dead building) and posts a `[combat] building destroyed` line into the chat overlay. Save format bumped to v8. 2 new sim tests cover the WAR-vs-NEUTRAL gating and IslandMap restoration after destruction
74. **Housing capacity gating** — `update_population_growth` now takes a `housing_cap: u32` (0 = uncapped). `tick_population` computes per-player capacity by summing 8 occupants per built `WOHN` residence and passes it through. After growth/promotion/emigration, if total population exceeds capacity, every tier is scaled proportionally so the surplus simply doesn't materialise that tick — preserves tier ratios while preventing unbounded growth. New `housing_cap_clamps_total` test seeds 600 population with cap 300 and asserts both the total clamp and the proportional scale-down
75. **Scenario objectives** — new `anno_sim::objectives` module with an `Objective` enum (ReachPopulation / Build prod_kind / AccumulateGold / StockGood) and `ObjectiveSet`. `tick_population` re-evaluates each unfulfilled objective against the human player; objectives only flip true (never revert), so spending past a gold target keeps the checkmark. `Simulation::default_starter()` ships a 4-objective tutorial (50 settlers / 1 marketplace / 10000 gold / 50 Tools). `?` opens the panel showing each line with a `[ ]` or `[x]`; completions are drained into the chat-log overlay as `[obj] complete: …` events. Save format bumped to v9; ObjectiveSet derives Default + Serde with `#[serde(default)]` for forward-compat. 2 new sim tests cover population objective + non-revert behaviour
76. **Sim event SFX** — game binary loads three additional WAV slots from SPEECH8 (1010/1020/1030, with fallbacks) and triggers them on milestone events: building destruction (drained from `tile_clears`), objective completion (drained from `objective_completions`), and any new diplomacy WAR transition. Plays via existing `WaveManager::play_once` at screen center. Slots fall back to the existing placement-sfx file if the dedicated WAV isn't shipped, so the integration degrades gracefully on stripped data installs
77. **Per-island climate** — new `anno_sim::climate` module: `Climate::{North, South}` derived from an island's `y_pos` (upper half = North), with `allows_production(climate, good)` gating tobacco/cocoa/sugar/spices/cotton/silk to South and wool/grain/flour/cattle/hides to North; everything else is climate-agnostic. The placer rejects mismatched plantations with a banner ("build FAILED: Tobacco needs South climate") and the inspection panel shows a colored Climate badge (cool blue North / warm orange South) so the player always knows what they can grow. 4 sim tests cover the y-split, climate-required goods both directions, and agnostic passthrough
78. **Residence promotion** — `BuildingInstance` gains `house_tier: u8` (0=Pioneer, 4=Aristocrat). `tick_population` runs a promotion pass before maintenance/cap calc: any built `WOHN` whose current tier is fully satisfied (sat ≥ 100) bumps `house_tier += 1`. Housing capacity now scales with tier via `HOUSING_BY_TIER = [4, 8, 12, 16, 20]`, so promoting residences also expands the housing cap that gates `update_population_growth`. Save format bumped to v10 for the new field. New `residence_promotes_when_tier_fully_satisfied` test
